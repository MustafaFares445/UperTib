## FR.03.1.2: Eligibility Explanation

## Requirement

**ID:** FR.03.1.2  
**Authoritative SRS ID:** FR-005  
**Title:** Eligibility Explanation  
**Priority:** Should Have  
**Status:** Approved

### Statement

The UberTib system should provide an on-demand explanation of provider eligibility for the selected service and branch, including the last assessment date and practical reason summary.

## Traceability

| Traces To | ID | Description |
|---|---|---|
| Customer Need | CN.03.1 | Patients need optional explanatory detail supporting their provider choice. |
| Customer Problem | CP.03 | Patients need understandable information rather than unexplained internal scores when choosing care. |
| Authoritative SRS | FR-005 | Preserved requirement identity from UberTib SRS v1.1 |

## Acceptance Criteria

- [ ] The explanation identifies the exact service and branch to which it applies.
- [ ] The explanation shows the last effective assessment date and patient-appropriate reasons without exposing confidential evidence or raw I.
- [ ] PENDING_EVALUATION is explained as insufficient evidence and is not presented as F.
